# 배송원 장비(운송 수단) 관리 및 단일 활성화 시스템 가이드

---

## 📌 1. 개요 및 배경

배송원(Courier)이 오토바이, 자동차, 자전거, 전동 킥보드, 드론 등 다양한 운송 수단을 다중 등록하고, 상황과 환경(날씨, 짐 무게)에 맞춰 하나의 주력 운송 수단을 활성화(Exclusive Toggle)하여 배달 콜을 수락할 수 있도록 지원하는 기능입니다.

---

## 🏗️ 2. 핵심 비즈니스 로직 및 도메인 규칙

### 2.1 승인 프로세스 (`VehicleApprovalStatus`)
- **승인 대상**: 법적 책임 및 면허/보험 검증이 필요한 동력 장치(`MOTORCYCLE`, `CAR`) 및 `DRONE`은 등록 시 기본 상태가 `PENDING`(승인 대기)입니다.
- **즉시 승인**: `BICYCLE`, `KICKBOARD`, `WALK`는 등록 시 즉시 `APPROVED`(승인 완료) 상태로 전환됩니다.
- **토글 제한**: `PENDING` 또는 `REJECTED` 상태의 장비는 활성화 토글 조작이 불가능(`disabled`)합니다.

### 2.2 배타적 단일 활성화 트랜잭션 (Exclusive Toggle)
- 한 배송원은 **동시에 단 1개의 장비만 `isActive = true`** 가 될 수 있습니다.
- 새로운 승인 완료 장비를 활성화 시 기존에 켜져 있던 다른 장비는 자동으로 `isActive = false`로 비활성화됩니다 (`@Transactional`).

### 2.3 종류별 동적 유효성 검사 (`@AssertTrue`)
- `MOTORCYCLE`, `CAR` 선택 시:
  - 차량 등록 번호(`licensePlateNumber`) 필수
  - 보험 가입 증명서 사본(`insurancePhotoUrl`, 5MB 제한 파일) 필수
  - 배기량(`displacement`, cc) 필수

## 🔌 3. API 엔드포인트 스펙

| HTTP Method | API Path | 설명 | 권한 |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/v1/vehicles` | 신규 장비 등록 | 배송원 |
| `GET` | `/api/v1/vehicles/my` | 내 소유 장비 목록 조회 | 배송원 |
| `PATCH` | `/api/v1/vehicles/{id}/activate` | 단일 활성화 토글 전환 | 배송원 |
| `PATCH` | `/api/v1/vehicles/{id}/approve` | 장비 승인 처리 | 관리자 (`ROLE_ADMIN`) |
| `PATCH` | `/api/v1/vehicles/{id}/reject` | 장비 반려 처리 | 관리자 (`ROLE_ADMIN`) |
| `DELETE` | `/api/v1/vehicles/{id}` | 장비 삭제 | 배송원/관리자 |

## 🎨 4. 프론트엔드 UI/UX 흐름

1. **GNB 탭 이동**: `courier-home.html` 하단 메뉴에서 **[장비]** 클릭 ➔ `/courier-equipment` 이동.
2. **장비 관리 목록 (`courier-equipment.html`)**:
   - 우측 상단 `+` 버튼 ➔ `/courier-equipment-new` (신규 등록 페이지).
   - 카드 스펙 요약: `배기량 125cc \| 적재 30kg` 또는 `최대 주행 50km \| 적재 20kg`.
   - 승인 상태 뱃지: `[승인 대기]`, `[승인 완료]`, `[반려]`.
   - 토글 스위치 클릭 ➔ *"기존 운송 수단이 해제되고 [장비명]으로 변경됩니다."* 알림 모달 출력 후 전환.
3. **신규 장비 등록 폼 (`courier-equipment-new.html`)**:
   - 상단 `←` 뒤로가기 버튼.
   - 종류 선택 드롭다운에 맞춰 동적 폼 자동 변경.
   - 5MB 용량 제한 미리보기 사진 첨부 UI.
