🎨 1. langchain-ai/open-canvas

에이전트-유저 협업
OpenAI Canvas 스타일의 문서/코드 저작 툴. Writer Node와 Reflection Node가 상태 메모리를 공유하며 사용자의 피드백 엣지에 따라 정교하게 분기합니다.

📚 2. Stanford STORM & Self-RAG / CRAG

자가 수정 RAG
검색 결과의 관련성에 따라 웹 검색 노드로 분기하고, 생성된 답변의 환각(Hallucination) 여부를 검증하여 검색 노드로 자가 회귀(Loop)하는 그래프입니다.
graph TD Query["🔍 질문/주제 입력"] --> Node_Retrieve["📥 문서 검색 노드 (Retriever Node)"] Node_Retrieve --> Node_Eval{"⚖️ 검색 품질 평가 노드 (Document Grader)"} Node_Eval -- "정보 부족 (Irrelevant)" --> Node_WebSearch["🌐 웹 검색 보완 노드 (Web Search)"] Node_WebSearch --> Node_Generate["📝 답변 생성 노드 (Generator Node)"] Node_Eval -- "정보 충분 (Relevant)" --> Node_Generate Node_Generate --> Node_HallucinationCheck{"👻 환각 검증 노드 (Hallucination Checker)"} Node_HallucinationCheck -- "❌ 환각 감지 (Fail)" --> Node_Retrieve Node_HallucinationCheck -- "✅ 무결점 (Pass)" --> End["🎉 최종 보고서 반환"] style Query fill:#2563EB,stroke:#fff,color:#fff style Node_Eval fill:#EAB308,stroke:#fff,color:#000 style Node_HallucinationCheck fill:#EF4444,stroke:#fff,color:#fff style End fill:#10B981,stroke:#fff,color:#fff

🤖 3. ozereray/langgraph-agentic-workflows

자가 치유 개발
기획, 리서치, 코딩, 리뷰, 자가 치유(Fixer) 노드가 결합된 Multi-Agent 파이프라인. 품질 검토 점수가 미달되면 Fixer 노드로 회귀 루프를 돕니다.
graph TD Task["🚀 업무 지시 (Goal)"] --> Node_Plan["📋 1. 기획 노드 (Planner)"] Node_Plan --> Node_Research["🔍 2. 리서치 노드 (Researcher)"] Node_Research --> Node_Write["💻 3. 작성 노드 (Writer/Coder)"] Node_Write --> Node_Review{"🛡️ 4. 리뷰 노드 (Reviewer Node)"} Node_Review -- "❌ 기준 미달 (Score < 80)" --> Node_Fix["🔧 5. 자가 치유 노드 (Fixer Node)"] Node_Fix -- "보정 코드 재주입" --> Node_Write Node_Review -- "✅ 기준 통과 (Score >= 80)" --> Node_HumanApproval["👤 6. 최종 승인 대기 노드 (Checkpoint)"] Node_HumanApproval --> Done["🎉 작업 완료"] style Task fill:#2563EB,stroke:#fff,color:#fff style Node_Review fill:#EAB308,stroke:#fff,color:#000 style Node_Fix fill:#EF4444,stroke:#fff,color:#fff style Done fill:#10B981,stroke:#fff,color:#fff

🏢 4. NVIDIA/generative-ai-examples

엔터프라이즈 멀티 에이전트
질의 특성에 따라 전문 도메인 에이전트(재무/법률/개발)로 동적 라우팅하고, 체크포인터 DB에 상태를 영속 보존하는 엔비디아의 파이프라인입니다.
